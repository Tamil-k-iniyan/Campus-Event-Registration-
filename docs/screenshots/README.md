# Application User Interface Screenshots Guide

This directory documents the key user interface views and workflow screenshots for the **Campus Event Registration and Management System**.

---

### Captured User Interface Views

1. **Home / Landing Page (`01_home_landing.png`):**
   - Premium hero section with university branding, platform KPIs (Total Events, Active Students, Confirmed Bookings).
   - Category exploration cards (Technical, Hackathon, Workshop, Cultural, Sports, Seminar).
   - Featured upcoming events grid with real-time seat availability gauges and deadline badges.

2. **Event Explorer & Search (`02_events_catalog.png`):**
   - Live search input matching keywords across titles, descriptions, and venues.
   - Interactive category pill filters and upcoming/past timeframe toggles.
   - Sorting options by event date (Earliest vs Latest) and responsive pagination controls.

3. **Event Details & Seat Booking (`03_event_details.png`):**
   - Comprehensive event syllabus, campus venue location, organizer department, and schedule.
   - Live seat capacity utilization bar and registration deadline warning.
   - Dynamic action button: One-Click Registration modal with optional attendee notes for students; Admin controls for faculty.

4. **Student Portal Dashboard (`04_student_dashboard.png`):**
   - Personalized welcome banner showing student roll ID and department.
   - Real-time stat cards: Total Confirmed, Upcoming Scheduled, and Completed Events.
   - Table of upcoming registered events with direct links to event details.

5. **My Registrations & Cancellation (`05_my_registrations.png`):**
   - Complete personal audit history of student seat bookings.
   - Status indicators (Confirmed vs Cancelled) and registration timestamps.
   - Self-service cancellation button with confirmation dialog and rule enforcement.

6. **Student Profile Management (`06_student_profile.png`):**
   - Student academic records (Name, Department, Roll Number, Phone).
   - Instant profile update form connecting to backend user persistence.

7. **Faculty Administrator Console (`07_admin_dashboard.png`):**
   - Executive metrics: Total Events, Upcoming Events, Registered Students, Confirmed Bookings.
   - Events Catalog with capacity utilization progress bars.
   - Quick management actions: Attendee Rosters, Edit, Delete.

8. **Event Attendee Roster & CSV Export (`08_attendee_roster.png`):**
   - Complete attendee table displaying student names, emails, phones, departments, roll IDs, notes, and booking timestamps.
   - Live search filtering by student name or roll ID.
   - Single-click **Export to CSV** button generating downloadable `.csv` spreadsheet files for faculty grading and offline records.

9. **Event Creation & Publication Form (`09_create_event.png`):**
   - Form fields: Title, description, category, event date, start/end times, venue, organizer, capacity, and registration deadline.
   - Multi-layer client and server validation with field-specific error feedback.
